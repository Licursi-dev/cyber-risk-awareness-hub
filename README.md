Cyber Risk & Awareness Hub

A cyber security awareness training platform designed to improve staff understanding of common cyber threats through interactive scenario-based learning.

Overview

The Cyber Risk & Awareness Hub is a browser-based cyber security training application designed to help organisations improve employee awareness of common cyber risks. The platform uses realistic workplace scenarios to teach users how to recognise and respond to cyber threats such as phishing attacks, credential theft, ransomware, business email compromise and data handling risks.

The application provides an engaging alternative to traditional cyber security awareness training by allowing users to actively participate in realistic situations rather than simply reading policies or watching presentations.

Project Inspiration

While studying cyber security, I learned that approximately 80% of cyber attacks involve some form of human error. This statistic highlighted an important challenge faced by organisations: even with strong technical security controls in place, a single mistake by a user can still result in a successful attack.

This led me to consider how staff training could be improved to help reduce human-related security incidents.

Traditional cyber awareness training often relies on presentations, documents and compliance exercises which can be difficult to engage with and may not fully prepare users for real-world situations. I wanted to create a platform that allowed users to learn through practical decision-making and realistic workplace scenarios.

The Cyber Risk & Awareness Hub was developed as a proof-of-concept training platform that demonstrates how interactive learning can be used to strengthen cyber security awareness. The project combines cyber security knowledge with software development skills to create a system that tracks user progress, assesses understanding and provides immediate feedback through scenario-based learning.

The project reflects an important principle of cyber security: technology alone cannot protect an organisation. Effective security requires informed users who understand the risks they face and know how to respond appropriately when threats occur.

Learning Approach

The platform uses scenario-based learning to reinforce cyber security concepts.

Users are presented with realistic workplace situations and must decide how they would respond. Each decision is evaluated against cyber security best practice guidance, with explanations provided to support learning and understanding.

This approach encourages active participation and allows users to apply knowledge in practical situations rather than relying solely on theoretical training.

Current Limitations

The current version is a prototype and stores user progress in memory while the backend is running.

As a result:

• Progress is lost when the backend restarts.

• User accounts are simulated using Staff IDs.

• Administrative access uses a simple PIN system.

Future versions could introduce database storage, user authentication, reporting dashboards and organisational management features.
